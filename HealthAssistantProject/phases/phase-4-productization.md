# Phase 4 - Productization

## Scope

- Persist user profile, scan reports, plans và workout sessions.
- Dashboard: scan, roadmap, today plan và real-time workout.
- Integration test cho toàn bộ luồng end-to-end.
- Đo precision, recall, góc đo, latency và chi phí LLM.

## Demo script

1. Scan chính diện/nghiêng và hiển thị report.
2. Sinh roadmap 6-8 tuần và daily plan.
3. Bật squat, cố tình sai tư thế để minh họa cảnh báo HUD/TTS.
4. Tập đúng, hoàn tất session và hiển thị tiến độ.

## Báo cáo AI

- Mô tả dataset, cách gắn nhãn, feature engineering và model selection.
- Báo cáo precision, recall, F1, MAE, latency và chi phí LLM.
- Phân tích lỗi, bias theo người/camera/view và các giới hạn an toàn.
